# Legacy Forms and Views Laboratory Reference

Деякі відновлені глави історично посилалися на forms/views laboratory notebook, якого немає в активній структурі цього репозиторію.

У поточному `notes_chat_app` цей матеріал збережено як reference note, щоб повні глави не мали битих локальних Markdown links і щоб навчальний контекст лабораторії не був втрачений.
