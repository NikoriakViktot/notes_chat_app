# Legacy ORM Laboratory Reference

Деякі відновлені глави історично посилалися на ORM laboratory notebook, якого немає в активній структурі цього репозиторію.

У поточному репозиторії `notes_chat_app` цей notebook не входить до активної структури. Посилання у повних главах перенесено сюди, щоб не залишати битих локальних Markdown links і водночас не втратити навчальний контекст про лабораторію ORM.

Якщо notebook буде повернуто у репозиторій, цей файл можна оновити прямим посиланням на актуальне місце.
