# URLs and Views

> URL pattern прив'язує path до Python callable, найчастіше view.

## Що студент вивчить

- базову ментальну модель теми;
- як тема працює у Django;
- де її побачити у фінальному проєкті;
- як перевірити, що розуміння не лише теоретичне.

## Передумови

- Вміти відкрити репозиторій.
- Розуміти, що всі шляхи в документації відносні до кореня `notes_chat_app`.

## Поточний стиль

Проєкт використовує function-based views. Старі матеріали про CBV збережені в архіві як теорія, але фінальний `views.py` зараз не використовує Django generic CBV.

## Приклад

`path('notes/', views.note_list, name='note_list')` означає: HTTP path `/notes/` викликає `note_list(request)`.

## Де це знайти у фінальному проєкті

| Файл | Що подивитися |
| --- | --- |
| `notes_app/urls.py` | app routes |
| `notes_app/views.py` | view functions |
