# How To Use This Course

> Документація побудована як книга, але її можна читати кількома маршрутами.

## Що студент вивчить

- базову ментальну модель теми;
- як тема працює у Django;
- де її побачити у фінальному проєкті;
- як перевірити, що розуміння не лише теоретичне.

## Передумови

- Вміти відкрити репозиторій.
- Розуміти, що всі шляхи в документації відносні до кореня `notes_chat_app`.

## Режими

- Студент: йде за `LEARNING_PATH.md`.
- Викладач: використовує `TEACHING_GUIDE.md`.
- Практик: відкриває `12_final_project/`.
- DevOps focus: переходить до `10_linux_and_devops/` і `11_deployment/`.

## Правило

Якщо документ описує теорію, шукайте блок `Де це знайти у фінальному проєкті`.

## Де це знайти у фінальному проєкті

| Файл | Що подивитися |
| --- | --- |
| `docs/LEARNING_PATH.md` | повний маршрут |
| `docs/12_final_project/README.md` | актуальний проєкт |

## Практичне завдання

Виберіть один маршрут і не стрибайте між старими archived docs без потреби.

## Контрольні питання

- Що є входом у цей процес?
- Який результат очікується?
- Де найчастіше виникає помилка?
- Яка команда або test допомагає перевірити зміну?
